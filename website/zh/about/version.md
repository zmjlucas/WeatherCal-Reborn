# 版本与验证 {#version-and-verification}

本文档描述提交`f428886`时的布局实现。
该实现包含自动视口识别、尺寸类别预设，以及有下限的字号回退。
文档站点与已安装的Scriptable脚本分别构建。

## 确认契约来源 {#contract}

仓库文件`docs/LAYOUT.md`说明布局契约。
实现位于`src/layout/`和`src/items/`。
已安装脚本的入口和可编辑用户区域分别来自`src/entry.ts`和`src/user.ts`。

本版本支持`small`、`medium`和`large`主屏幕小组件。
它不支持超大尺寸和配件类小组件。
旧版逐行命令、ASCII布局和设置对象布局需要[迁移](../guide/migrate.md)。

## 验证范围 {#test-evidence}

| 证据 | 能够证明的范围 |
| --- | --- |
| 解析器与规划器测试 | 受控输入下的语法行为、约束、几何尺寸和有限搜索 |
| 共享示例测试 | 人工设定内容项测量值下的示例行为 |
| 站点构建与链接测试 | 文档结构、示例导入和站内导航 |
| 浏览器检查 | 浏览器中的站点显示与导航 |
| 原生设备检查 | 被测设备上的实际文本、裁切、点击、背景和刷新行为 |

共享示例使用320 × 160逻辑点的示例视口，并非手机实测尺寸。
浏览器中的图是结构示意图，不是Scriptable预览。

本文档未提供真机测试结果。
请按[真机检查流程](../guide/device-checks.md)测试你的配置。

## 语言与写作 {#language-and-writing}

英文是本文档的源语言。
中文页面遵循英文结构，并共享代码示例。
文档采用短句和[术语参考](./terminology.md)中的统一术语。

英文写作遵循ASD-STE100简化技术英语原则。
尚未逐条核验全部词典条目和写作规则的符合情况。

# 真机检查 {#device-checks}

仓库测试使用模拟测量值和模拟视图，无法检测手机上的实际文本裁切。
请按以下流程在设备上检查规划出的布局。

## 记录测试条件 {#record-the-test-conditions}

每次真机测试都记录以下信息：

| 信息 | 示例或用途 |
| --- | --- |
| 设备与操作系统版本 | 标明实际测试的硬件和软件。 |
| 小组件尺寸类别 | `small`、`medium`或`large` |
| 显示缩放与图标大小 | 标明可能改变小组件尺寸的设置。 |
| 视口来源与尺寸 | 记录自动识别结果或手动覆盖值。 |
| 布局与字体偏好 | 保留准确的测试输入。 |
| 语言与数据状态 | 包括长文本和数据不可用状态。 |

## 检查几何尺寸 {#do-the-geometry-checks}

1. 为测试配置[获取可用的小组件尺寸](./viewport.md#obtain-usable-dimensions)。
2. 用逻辑点记录小组件宽度和高度。
3. 比较应用内预览与主屏幕小组件。
4. 用可见背景或边框检查固定区域。
5. 检查根内边距、内容项内边距和间距。
6. 用尺寸已知的内容检查对齐方式。
7. 确认每个已选内容项实例都出现一次。

如果实测边界与屏幕配置不同，请设置[视口覆盖值](./viewport.md#set-a-manual-override)。

## 检查内容 {#do-the-content-checks}

1. 检查较长的英文和中文标题。
2. 检查零下温度。
3. 检查下一小时和明日内容。
4. 检查分别显示的白天和夜间降雨概率。
5. 检查空日程和空提醒事项。
6. 检查天气和太阳事件数据不可用的状态。
7. 检查布局实际使用的每个自动字号阶段。

内容项原有的行数限制仍然有效。
规划器在估计高度时会考虑这些限制。

## 检查交互与运行 {#do-the-behavior-checks}

1. 检查小尺寸小组件的点击动作。
2. 检查中、大尺寸小组件的内容项链接。
3. 检查小组件背景。
4. 记录刷新请求与实际刷新时间。
5. 运行一个接近文档所列[规划限制](../explanation/planning.md#limits)的布局。
6. 记录运行时间和内存占用。

小尺寸小组件的整个区域共用一个点击目标。
iOS可能在请求时间之后才刷新小组件。
不要把未测试的设备配置报告为已验证。
